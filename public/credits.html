ABOUT THE APP

Open-source credits

Chess Studio is independent of Chess.com and Lichess. Their names identify the public game services that users can choose to query; neither platform endorses this app.

Engine and board

Stockfish 19 Lite powers optional local analysis. Stockfish is free software under the GNU GPL version 3. The license text ships with the engine, and the upstream source is available publicly.

Cburnett chess pieces are credited to Colin M. L. Burnett. The Lichess attribution lists the pieces under GPL version 2 or later. Read the GPL version 2 text.

chess.js by Jeff Hlywa supplies chess rules and move validation under the BSD 2-Clause license. See its source.

Openings and application code

The opening catalog is generated from lichess-org/chess-openings (CC0). Game reporting and public API adapters were adapted from the owner's MoveMirror project. The Chess Studio source repository contains the app, Android wrapper, and build instructions.

The Android app uses AndroidX WebKit, licensed under Apache 2.0.
